# Campus Tour – Unity Project

## Overview
A Unity-based first-person 3D campus navigation experience designed to help users explore and find rooms within a university teaching block.
## Features
- First-person navigation
- 3D indoor environment
- Room-finding support
- Smooth movement and camera controls

## Tech
- Unity
- C#

## How to Run
1. Open the project in Unity Hub
2. Load the main scene
3. Press Play
